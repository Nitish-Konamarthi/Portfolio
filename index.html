Featured · In Development

TokenSentry — AI Governance & Model Routing Layer

A plugin-based proxy that sits between coding agents and upstream LLM APIs. It intercepts requests to enforce usage policies and token budgets without changing the agent's workflow, and a cost-aware routing engine selects a model per request from provider, capability and pricing metadata. Governance logic is kept separate from provider connectivity and API-key handling, so it stays provider-agnostic. Not yet launched.

Node.js Fastify TypeScript LLM APIs Proxy Architecture
Launch pending
Flagship Project
🫁

Chest X-Ray Diagnostic Assistant

An AI diagnostic system that classifies 14 chest pathologies with a DenseNet-121 model (87.8% accuracy), generates Grad-CAM++ heatmaps for explainability, and uses Gemini to produce clinical explanations. A FastAPI inference backend validates and preprocesses images before inference, and a Geoapify-powered finder suggests nearby specialists. Deployed on Vercel and Hugging Face Spaces.

FastAPI PyTorch DenseNet-121 Gemini API Grad-CAM++ React 18 Geoapify
